Search the current user's cross-session memories (facts, preferences, decisions, gotchas remembered from earlier sessions).

## When to Use
- When the user references something from a previous session ("as we decided last week…").
- Before making assumptions about user preferences, environment details, or past decisions.
- The session-start `<user-memories>` block already shows the top items; use this tool to look up specifics beyond it.

Matching is case-insensitive substring search; results are ranked by salience and recency. Only active (non-forgotten) memories are returned.
