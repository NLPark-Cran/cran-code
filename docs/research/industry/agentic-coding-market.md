## 二、范式演进：从代码补全到 Agentic Coding

### 三代演进

| 代际 | 时间 | 代表产品 | 核心特征 | 用户角色 |
|------|------|----------|----------|----------|
| G1 代码补全 | 2021-2023 | GitHub Copilot | 单行/函数级补全，IDE 插件，被动 Tab 触发 | 打字者 |
| G2 对话式编程 | 2023-2024 | ChatGPT, Claude | 理解意图、生成代码块、多轮对话 | 编辑者 |
| G3 智能体编程 | 2025+ | Claude Code, Cursor Agent, Codex | 自主规划、多步执行、工具调用、长程任务 | 监督者 |

### 2026 年五大范式特征

1. **计费方式**：固定订阅 → 订阅+软上限 → Usage/Outcome
2. **时间单位**：秒 → 分钟 → 小时/天
3. **失败成本**：零 → 低 → 中-高
4. **用户角色**：打字者 → 编辑者 → 监督者
5. **交互单位**：一行代码 → 一个函数 → 一个任务

> **关键洞察**：2026 年分水岭 — Agent 型工具首次取代 IDE 型工具，成为新增付费订阅的主要驱动力。开发者付费意愿从"辅助生产"迁移到"替代生产"。

## 三、技术趋势（2026）

### 1. 长程 Agent（Long-running Agents）

- 早期 Agent：几分钟完成的单次任务
- 2025 下半年：数小时完成完整功能集
- 2026：可工作数天甚至数周，构建完整应用和系统
- **对猹询码的意义**：24 小时服务器持续运行、长程任务不被本地关机打断，正好切中这一趋势

### 2. 多智能体协作（Multi-agent Systems）

- 组织采用多 Agent 工作流，通过并行推理最大化性能
- 示例：Fountain 平台使用分层多 Agent 编排，实现 50% 更快筛选、2 倍转化率
- **对猹询码的意义**：服务端作为"中枢 Agent"，协调多个专项 Agent 完成开发、部署、运维

### 3. MCP（Model Context Protocol）生态爆发

- 2026 年 MCP 成为事实标准，解决智能体"孤岛化"问题
- 兼容 MCP 的工具：Claude Code、Cursor、Codex、Kimi CLI、OpenCode
- 目前最大跨工具技能库：Antigravity Awesome Skills（1,234+ 技能，22,000+ Stars）
- **对猹询码的意义**：已移植 MCP 和 Skills 机制，可接入更多工具生态

### 4.  Coding 民主化（Beyond Engineering）

- AI 编程从专业开发者扩展到销售、市场、法律、运营等非技术角色
- Zapier 89% 的员工使用 AI，800+ 内部 Agent 部署
- **对猹询码的意义**：文科生也能编程的差异化定位，顺应"全民开发"趋势

## 四、中国市场特殊机遇

### 1. 国产化替代浪潮

- Cursor 2025 年对中国大陆用户模型断供
- 字节跳动、百度等企业禁用 Cursor（代码上传国外服务器）
- **国产自主可控成为刚需**，猹询码"全程只用中国产品+开源产品"是核心卖点

### 2. 国产模型崛起

| 模型 | 厂商 | 编程能力 | 特点 |
|------|------|----------|------|
| Kimi K2 | 月之暗面 | 国产最强长程编程 | 1024 上下文，Agentic 能力强 |
| Qwen3-Coder | 阿里 | SWE-bench 领先 | 32B/72B 多尺寸，开源 |
| DeepSeek V3 | 深度求索 | 推理+代码双强 | 低成本高性能 |
| MiniMax M3 | MiniMax | 多模态+1M 上下文 | 国产最长上下文窗口 |

### 3. 开源工具窗口期

- Kimi CLI 已逐步停止维护（转向 TypeScript 产品线）
- 开源社区急需有团队接手维护并创新
- OpenCode、MonkeyCode 等开源项目快速崛起
- **猹询码基于 Kimi CLI fork，具备先发优势**
